# advisory

Surface agreement, disagreement, and objections among simulated stakeholders with conflicting incentives.

## Use

> Consult AP on this plan. Give the natural default, closest alternative, and the conditions that would change the choice.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `advisory/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
